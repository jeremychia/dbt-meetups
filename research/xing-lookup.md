# xing lookup

These people are in a German-speaking chapter and can't be messaged yet: none has a LinkedIn, Meetup, X or Bluesky profile on file. XING can't be searched from the research tools, so look them up while logged in to XING.

**How to use it**

- **Search:** the name link opens a XING member search for that name.
- **Match:** accept a profile only when it shows the employer, the talk or the community given here. Same rule as for LinkedIn: a data role in the right city is not enough.
- **Record:** paste the profile link (`https://www.xing.com/profile/...`) after the arrow and tick the box. A Claude Code session can then add the links with `research/apply_contacts.py` as profiles of type `xing`.
